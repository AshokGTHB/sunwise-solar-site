SUNWISE INDIA — WEBSITE STARTER
================================

Files:
- index.html: responsive single-page website with an interactive solar savings estimator and basic SEO metadata.

Preview locally:
1. Extract the ZIP.
2. Open index.html in a browser.

Publish free (example: GitHub Pages):
1. Create/sign in to a GitHub account.
2. Create a public repository named sunwise-solar-site.
3. Upload index.html and README.txt.
4. Open repository Settings -> Pages.
5. Choose Deploy from a branch, select main and /(root), then Save.
6. GitHub will provide a public URL after deployment.

Before publishing:
- Replace https://YOUR-DOMAIN.example/ in the canonical link with your real URL, or remove the canonical tag until you have a domain.
- Replace hello@YOUR-DOMAIN.example with a real contact email or change the contact action.
- Update the site name/contact details as desired.
- The calculator is an illustrative planning estimate, not an engineering quote. Review assumptions and local rules before relying on it.
- Add separate, genuinely useful pages for specific search intents (e.g. rooftop solar cost in Tamil Nadu, on-grid vs hybrid, installer checklist). Avoid keyword stuffing or copied content.
- Add the deployed site to Google Search Console and submit a sitemap once you have multiple pages. Indexing and ranking are not guaranteed.
